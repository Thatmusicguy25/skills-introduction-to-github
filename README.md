## Shorts Studio

This repository also includes a small, dependency-free creator dashboard in `index.html`. Open it in a browser to:

- Generate a hook, script outline, caption, and hashtags for a short-form video.
- Get platform-specific posting-time starting points.
- Estimate monthly ad revenue from views and RPM.
- Save ideas locally in a content queue.

The app is intentionally client-side: it does not upload videos or promise monetization. Connect your own platform APIs, analytics, storage, and eligibility checks before using it in production.
